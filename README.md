# TMR10 Swing Signal / 自動株価スキャナー

CSV不要のスイングトレード研究ツール。株価をYahoo Finance（非公式の市場データ経路、yfinance経由）から取得し、**確定した日足**で三角保合いの上抜け、20日高値上抜け、20日線反発をスキャンします。TMR10採点・セクター・決算は未接続です。自動売買はしません。

## 最短の使い方（PC）

1. Python 3.11以上を用意する。
2. フォルダ内で `pip install -r requirements.txt` を実行。
3. `streamlit run app.py` を実行。表示されたURLをブラウザで開く。
4. 「最新の確定日足を取得・判定」をクリックする。

## スマホで使う

Streamlit Community CloudなどにGitHubリポジトリを接続して `app.py` をデプロイする。サービス側の制限・公開設定を確認する。

## 外部通知（オプション）

GitHubにこのフォルダをリポジトリとして登録し、Actionsを有効にする。TelegramのBotを作成し、リポジトリのSecretsに `TELEGRAM_BOT_TOKEN` と `TELEGRAM_CHAT_ID` を設定すると、Actionsの定時スキャンで新しい確定シグナルのみ通知する。時刻はUTCで設定され、米国市場の夏時間・祝日・データ反映遅延等でタイミングがずれることがある。Actionsには起動遅延や実行欠落があるため、ピンポイント通知・完全監視を保証しない。データが欠損した場合は通知しない。

初回のスキャンで過去の最終確定足にシグナルがある場合、初回通知の対象になり得ます。Github Actionsのコミット権限を有効にして `signal_state.json` を更新する方式です。公開リポジトリ利用時はトークンをコードに書かず、Secretsを利用してください。

## 重要な限界

- `yfinance` はYahoo Financeの非公式ライブラリであり、レート制限・欠損・仕様変更がありえます。株価の精度・完全性は保証できません。
- ここでの三角保合いは20営業日の高値と安値の一次回帰直線の収束による**簡易近似**であり、人間によるチャート読解と一致しないことがあります。
- エントリーの期待リターンは検証されていません。上抜け・出来高増は勝率を保証しません。バックテスト、決算確認、流動性、売買手数料、ギャップ損失の検討が必要です。
- 20日線の判定は厳密なローソク足パターンや市場全体の強弱を含みません。
- 損切りは参考水準であり、逆指値の約定価格保証ではありません。
